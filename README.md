# ☕ JAVA_PRACTICE

A hands-on learning journal where I practice Java from the basics, one small project at a time. New projects are added every day or two, each building on the last.

## 🎯 Goal

Build a strong Java foundation, from variables and loops to object-oriented programming, by writing real code every day and pushing it to GitHub.

## 📁 Repository Structure

```
JAVA_PRACTICE/
└── src/
    ├── day01_hello_world/
    │   └── HelloWorld.java
    ├── day02_.../
    └── ...
```

Each day lives in its own package (`dayXX_topic_name`), so projects stay separate and easy to find.

## 🗺️ Learning Roadmap

1. **Basics:** syntax, variables, data types, operators
2. **Control flow:** conditions and loops
3. **Methods:** reusable blocks of code
4. **Arrays and Strings**
5. **OOP:** classes, objects, encapsulation, inheritance, polymorphism, abstraction
6. **Collections:** `ArrayList`, `HashMap`
7. **Exception handling and file I/O**
8. **Mini projects** combining everything

## ▶️ How to Run

**Requirements:** JDK 17 or newer, and IntelliJ IDEA (or any Java IDE).

**In IntelliJ:**
1. Clone the repository:
   ```bash
   git clone https://github.com/Farhan-Mirza/JAVA_PRACTICE.git
   ```
2. Open the folder in IntelliJ IDEA.
3. Open any `dayXX` file and click the green ▶ next to `main`.

**From the terminal:**
```bash
cd src
javac day01_hello_world/HelloWorld.java
java day01_hello_world.HelloWorld
```
